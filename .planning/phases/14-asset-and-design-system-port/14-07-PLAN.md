## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-04 | Elevation | chrome://prometheus-theme-preview accessible in release build | mitigate | PrometheusThemePreviewUIConfig and its registration wrapped in #if DCHECK_IS_ON(); release builds have DCHECK_IS_ON() false; page is unreachable |
| T-14-21 | Tampering | Preview HTML using sets=ui instead of sets=chrome | mitigate | HTML hardcoded to `?sets=chrome`; Pitfall 2 from 14-RESEARCH.md; DESIGN-07 visual check will catch if CSS vars are missing |
| T-14-22 | Tampering | Views gallery bypassing ColorProvider for direct hex hardcoding | mitigate | InsertColorRow() uses GetColorProvider()->GetColor(color_id) exclusively; no hardcoded hex in gallery view |
| T-14-SC | Tampering | npm/pip/cargo install | accept | No packages installed in this plan |
</threat_model>
