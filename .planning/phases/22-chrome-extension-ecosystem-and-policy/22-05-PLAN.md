callback. That continues through
`DeveloperPrivateLoadUnpackedFunction::FileSelected` and `UnpackedInstaller`;
it does not install directly or bypass verification. The factory is consumed
once and removed before any other dialog. The controller then drives real
inspect/reload/disable/enable/remove controls, observes registry transitions,
exercises local policy and a visible surface, writes only bounded stage/result
metadata, and tears down every callback/process/file/profile.

`GetSenderWebContents()->GetLastCommittedURL()` as the `caller` argument to
`SelectFileDialog::SelectFile` after confirming the sender is the live
`chrome://extensions` WebContents. It changes no install decision and exposes
no Prometheus hook. Unit tests prove ordinary callers retain native behavior
and that null, changed, non-manager, or destroyed senders cannot satisfy the
smoke chooser.
Optional Store probing uses a separate disposable profile and a version-pinned
benign extension through native install UI; it records only build, time,
`Verified live|Unavailable|Unverified`, and a sanitized reason. No credential,
URL query secret, extension inventory, content, or authority enters logs/docs.
