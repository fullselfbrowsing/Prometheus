<interfaces>
External SubmitTask accepts bounded prompt, mcp origin, requested automatic/
provider/local, server-derived caller identity, and its existing Agent session.
For local UI, CreateSidePanelPrincipal takes the exact originating Browser and
stable tab, asks PrometheusAgentProfileService for a browser-issued session, and
returns a move-only RAII C++ object held only by the WebUI handler. Its opaque
session/ownership IDs are never serializable. SubmitSidePanelTask requires that
object; submit and every tool call revalidate profile, exact Browser, attached
tab, Agent session, and ownership. Destruction, WebUI teardown, tab detach,
session loss, or profile shutdown cancels its tasks and calls CloseSession to
release ownership. AgentProfileService adds only a C++
ExecuteBrowserLocalRoute(exact Browser, request, callback) seam that rejects a
foreign Browser and is not a gateway/runtime route. A successful submission
returns only a task ID. Automatic chooses the ordered eligible registry route;
provider excludes local-only routes; local requires an already running loopback
OpenAI-compatible endpoint. DiscoverModels is a cancellable typed service call
that updates registry discovery state/health on supported success, unsupported,
or sanitized failure. Sensitive provider mutation accepts a caller-origin enum
and returns LOCAL_UI_REQUIRED for MCP; only the local control WebUI may change
endpoint, route, fallback, rates, enabled/trust state, or secret metadata.
Closed autonomous tools are
bounded page read/snapshot and safe typed click/type/key/scroll/hover/select/
clear actions only; execute_js, shell, filesystem, arbitrary fetch, extensions,
internal surfaces, and secret operations are never model-selectable.
</interfaces>
