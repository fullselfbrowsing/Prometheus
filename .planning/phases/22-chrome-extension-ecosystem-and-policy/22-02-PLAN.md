`prometheus_agent_route.h` and an optional `extension_surface` member to
`AgentTarget`; absence continues to mean the exact top-level tab. The native
transport and MCP schema accept only `"popup"` or `"side_panel"` in the
`extension_surface` field, require a positive stable `tab_id`, reject
`tabIndex`, unknown values, and any caller-supplied extension ID/URL/frame/
renderer/WebContents identity, and round-trip the selector in target results.
The stable tab anchors the exact Browser and tab; browser-owned popup or active
side-panel state must resolve to exactly one current `WebContents`, otherwise
the request fails typed instead of choosing the active or first match.

`PrometheusExtensionSurfaceResolver` accepts the exact resolved Browser/tab and
committed primary frame, derives the extension ID from the committed origin,
re-queries the enabled `ExtensionRegistry`, checks exact `BrowserContext`, and
returns a closed visible surface kind plus a policy snapshot generation. Its
accepted kinds are top-level tab/options, shown popup, active side panel, and a
positively proven visible options guest. `PrometheusExtensionPageAdapter`
accepts that browser-only resolution, not a caller ID or URL. Read-only routes
are `read_page`, `get_dom_snapshot`, `get_page_snapshot`, `get_text`, and
`get_attribute`; Interact additionally permits `click`, `type`, `press_key`,
`scroll`, `hover`, `select_option`, and `clear`. `execute_js`, drag/drop,
background invocation, DevTools, raw protocol, and every authority-bearing
route return stable extension-policy errors with the exact UI-SPEC recovery
copy.

browser reconstructs exact identity, context, visibility, grant, action family,

| T-22-04 | mitigate | Exact BrowserContext and separate effective Private grant are checked at admission and execution despite shared registries. |
| T-22-05 | mitigate | Exact route allowlists enforce Read only versus Interact, execute_js is structurally unreachable, and existing ownership/document/confirmation/verification are repeated before mutation. |
| T-22-06 | mitigate | Closed results, errors, and audit contain bounded metadata only and pass recursive content/full-ID/authority sentinel scans. |
| T-22-08 | mitigate | IDs are re-queried after reload/lifecycle transitions, generations fence callbacks, and disabled/terminated/uninstalled surfaces cannot dispatch. |
| T-22-09 | mitigate | HTTP(S)-only normal-page classification remains unchanged; local content-script tests prove DOM provenance cannot select extension authority. |
| T-22-10 | mitigate | Resolver/result/audit collections and strings use fixed bounds with over-limit tests and deterministic failure/truncation. |
